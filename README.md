# Большой Маршрут

Готовый прототип игры: заезд → ЭКТО и ямы → финиш → призовой барабан → выбор одного оффера → демо-кабинет.

## Открыть по ссылке

Включите GitHub Pages в [Settings → Pages](https://github.com/VladaRemizova/game2/settings/pages):

1. Source: **Deploy from a branch**.
2. Branch: **main**, папка **/ (root)**.
3. Нажмите **Save** и дождитесь публикации.

После публикации адрес игры: https://vladaremizova.github.io/game2/

## Открыть локально

Скачайте `index.html` и откройте в браузере. Игра целиком в одном файле; интернет и установка не нужны.

## Проверить барабан сразу

Нажмите «45 жетонов · 3 вращения» → «Обменять жетоны на офферы». Сделайте три вращения и выберите один оффер. Справа находится схема логики и пояснения текущего шага.

## Данные

Игровые данные не отправляются. Нет аналитики, внешних библиотек, шрифтов и изображений. Все расчёты выполняются в браузере; локально хранится только демонстрационный приз и день его получения. Призы недействительны на АЗС.

Прототип использует только призовой барабан с восемью непустыми секторами. Пулы и часть номиналов демонстрационные; допущения перечислены в интерфейсе.
