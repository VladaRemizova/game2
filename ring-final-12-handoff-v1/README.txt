LA VIVION · 12 колец для финального веб-просмотра

Круг — LR2882BR01, LR2981BR01, LR2906BR01, LR5600BR01
Овал — LR2882OV01, LR2981OV01, LR2082OV01, LR0211OV01
Принцесса — LR2882PR01, LR2981PR01, LR2906PR01, LR2411PR01

Свет центральных камней соответствует ring-four-cuts-source-gem-v1.html.
Круг использует «Тёмные акценты». Овал и принцесса используют v12.
Свет оправы и дорожки — v12. Индекс преломления — 2,42.

Распакуй архив целиком в одну папку. Открой index.html через локальный
или рабочий HTTP-сервер для проверки. Каталог загружает одну выбранную модель.

Для финального экрана игры используй <артикул>/index.html в iframe.
Оставь GLB и settings.json рядом с этим HTML. Общие viewer.js,
final-motion.js и draco/ должны быть на уровне папки артикула.
Освещение и преломление воспроизводятся связкой HTML, viewer.js и GLB.

В models.json указаны артикулы и пути. Модуль предоставляет window.ringViewer
и API diamond-final-v1. final-motion.js уже подключён в HTML артикула.
Для экспорта PNG отправь активному iframe сообщение
{scope: "diamond-final", type: "snapshot"}. Ответ с type: "snapshot"
содержит PNG blob в фиксированном ракурсе, шириной 1500 пикселей.
При области просмотра 375 × 376 размер PNG — 1500 × 1504.
