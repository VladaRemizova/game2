LA VIVION · 8 колец

Две оправы: с дорожкой и с ободком. Четыре огранки в каждой оправе.
Металл, мелкие камни, овал и принцесса — принятый v12.
Центральный круг — «Тёмные акценты» из просмотра круга.
Центральная изумрудная огранка — «Вариант Б» из просмотра изумруда.
Быстрый шейдер v12, IOR 2.42, экспозиция 1.15. Геометрия и текстуры сохранены.
Пробные переключатели света убраны. Доступны выбор оправы и огранки,
ракурсы ¾/сверху, вращение мышью и пальцем, пауза и исходный ракурс.

Отдельный HTML рядом с архивом — самодостаточный файл для презентации,
открывается без сервера и внешних библиотек. Он содержит 8 моделей,
но показывает и декодирует только выбранную.

Для сайта: распаковать ZIP целиком и открыть index.html через HTTP.
Веб-версия загружает только выбранный GLB; при выборе другого кольца
предыдущий просмотр удаляется и освобождает WebGL-контекст.
