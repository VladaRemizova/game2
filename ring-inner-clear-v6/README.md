# Кольцо — светлый ободок, прозрачные грани v6

Готовая статическая страница: только 3D-кольцо и кнопки «Пауза / Вращать» и «Исходный ракурс». Кольцо автоматически вращается; мышь, палец и приближение сохранены. При настройке ОС «Уменьшение движения» автоповорот отключён до нажатия «Вращать».

## Размещение на GitHub Pages

1. Распакуй ZIP и загрузи всё его содержимое в корень репозитория или в отдельную папку сайта, сохранив структуру файлов. Если Pages уже работает, достаточно добавить папку в опубликованную ветку.
2. Для нового сайта включи Pages в Settings → Pages и выбери ветку и папку публикации.
3. Открой адрес Pages или адрес добавленной папки: стартовая страница — `index.html`.

Сборка и npm на сервере не нужны. Все необходимые ресурсы лежат рядом: `viewer.js`, `ring-web-v1.glb`, `draco/`. Загружай их вместе с `index.html`; внешние CDN, шрифты и HDR-карты не используются. Папку `licenses/` сохрани при передаче.

## Локальный просмотр

Открой папку через любой локальный HTTP-сервер, например `python3 -m http.server 8000`, затем адрес `http://127.0.0.1:8000/`. Эта версия предназначена для веб-размещения; двойной щелчок по HTML не заменяет HTTP-сервер.

## Внешний вид

Освещение металла и светлый ободок сохранены из версии v5 от 15.10.2026. Модель, текстуры, гравировка и локальное осветление внутренней поверхности не изменены. В шейдере всех камней ослаблено широкое поверхностное отражение, которое давало белёсую пелену поверх внутренних граней. Внутреннее преломление и отражения сохранены; по скользящим углам внешний блеск возвращается плавно. Нейтральное окружение камней сделано контрастнее между источниками света, сами световые карты сохранены. Из сборки исключены шапка, выбор света, подписи и видимые подсказки.

Данная коррекция — художественная настройка веб-шейдера. Сила поверхностного отражения по сравнению с v5: 0,12 у центрального камня и 0,22 у мелких, с плавным возвратом к полной силе на скользящих углах. Фоновая яркость окружения камней: [0,085; 0,18; 0,34] вместо [0,18; 0,34; 0,58]. Глобальная экспозиция 1,15 и качество внутреннего трассирования прежние. Новые текстуры и дополнительные запросы не добавлены.

GLB — 2 967 256 байт, 153 300 треугольников, 37 камней. Для такого же вида в игре нужно переносить просмотрщик, его окружение и шейдеры вместе с моделью.
