# Кольцо — финальная версия по комментариям заказчика, v12

19 октября 2026. Основа внешнего вида — v6 (`ring-inner-clear-v6`). Опубликованные заказчиком v6 и v11 сверены с локальными файлами просмотрщиков по SHA-256: совпадают. Предыдущие версии не перезаписаны.

## Что изменено

1. **Металл светлее, чёрный блик остаётся чётким.** Геометрические тёмные отражатели, их положения и размеры взяты из v6. Дополнительного размытия окружения металла нет. Поднято нейтральное светлое заполнение и осветлены серые края белых отражателей. PMREM 512 на грань, blur 0; исходные карты металла, гравировка и множитель шероховатости 0,60 сохранены. Светлая внутренняя поверхность ободка сохранена по схеме v6.
2. **Камни разделены по расположению.** Один центральный, 18 в ободке вокруг центра, 18 в дорожке. Для ободка сохранено окружение v6, добавлена только малая шероховатость. Для центра и дорожки увеличены белые источники, добавлены два нейтральных белых отражателя и более светлое заполнение между ними. Чёрные отражатели сохранены.
3. **Карты камней строго обесцвечены.** Ни цветных отражателей, ни тёплых HDR в них нет. В диагностической сборке проверены все шесть граней каждой карты 512×512: максимальная разница RGB-каналов — 0. Возможные небольшие цветные вспышки центрального камня создаёт моделируемая дисперсия преломления, как в v6. Усиленная дисперсия v7–v11 не используется. Мелкие камни используют ахроматическое приближение v6.
4. **IOR 2,42.** Значение проверено в каждом активном материале просмотрщика и явно записано в материалах GLB. Базовая трассировка, форма граней, коэффициенты поверхностного отражения 0,12/0,22 и число внутренних отражений 12/7 взяты из v6. Принудительного размножения бликов и отдельной анимации мерцания нет.
5. **Немного смягчены переливы камней.** Равномерная roughness: центр и дорожка 0,018, ободок 0,014. В специальном веб-шейдере это узкое детерминированное угловое усреднение света и фильтрация карты — приближение малой шероховатости без изменения плоских нормалей огранки. Новая текстура Roughness не потребовалась. В GLB записаны такие же значения для стандартного материала. Случайный шум по кадрам не добавлен.
6. **Стабильность при вращении.** Адаптация производительности меняет плотность пикселей, сохраняя число внутренних отражений. При паузе и возобновлении рисунок камня не переключается на другой режим.

## Что внутри

- `index.html` — чистая страница с кнопками «Пауза / Вращать» и «Исходный ракурс».
- `viewer.js` — просмотрщик, настройки освещения и специальный материал бриллиантов.
- `ring-web-v1.glb` — модель с упакованными текстурами и нейтральными материалами. Геометрия и текстурный бинарный блок побайтно совпадают с v6; изменён только JSON материалов и метаданные групп камней.
- `draco/` — локальный декодер сжатой геометрии.
- `studio-settings.json` — снимок настроек для передачи разработчику; просмотрщик уже содержит эти настройки и не загружает JSON отдельно.
- `licenses/` — лицензии используемых библиотек.

Геометрия — 153 300 треугольников, 37 камней. GLB в другом просмотрщике не повторит этот свет и специальное преломление автоматически: для интеграции нужно переносить модель, просмотрщик, окружение и шейдеры вместе. Производительность всей игровой сцены и реальных телефонов проверяется при интеграции; здесь проверяется отдельное кольцо в браузере.

## Размещение и локальный просмотр

Распакуй ZIP и загрузи всё содержимое в корень репозитория GitHub Pages или в отдельную папку сайта, сохранив структуру. В корне ZIP лежит `index.html`. Для нового репозитория включи Pages в Settings → Pages и выбери ветку и папку. Сборка и внешние CDN не нужны.

Локально открой папку через HTTP-сервер, например `python3 -m http.server 8000`, затем `http://127.0.0.1:8000/`. Двойной щелчок по HTML не заменяет сервер. Мышь, палец, приближение и автоповорот сохранены; настройка ОС «Уменьшение движения» отключает автоповорот до нажатия «Вращать».
