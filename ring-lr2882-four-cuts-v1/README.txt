Кольца LR2882 · четыре формы центрального камня · v12

В комплекте:
LR2882BR01 — круглый бриллиант.
LR2882OV01 — овальный бриллиант.
LR2882PR01 — квадратный, princess.
LR2882EM01 — прямоугольный, emerald.
Это одна серия оправ; верхняя закрепка соответствует огранке камня.

Для GitHub Pages распакуй ZIP и загрузи всё содержимое папки в выбранный
каталог репозитория. Стартовая страница — index.html. Сохраняй структуру
папок: четыре папки моделей, общий viewer.js, draco/ и licenses/.
Если репозиторий публикует архивы через свой процесс сборки, используй
этот ZIP как исходный статический комплект, распаковываемый при публикации.

При открытии загружается только выбранная 3D-модель. Переключение заменяет
предыдущий просмотрщик. Каждое кольцо также открывается по отдельной ссылке.
GLB находится в папке артикула под именем ring-web-v1.glb.
Освещение, материалы и геометрия взяты из готового пакета v12 без изменений.
Общий скрипт и декодер вынесены в отдельные файлы, GLB не дублируются в HTML.

Это комплект для статического сайта. Для локального просмотра нужен
локальный HTTP-сервер; открытие index.html через file:// не загружает GLB.
Страницы помечены noindex,nofollow. Лицензии библиотек — в licenses/.
