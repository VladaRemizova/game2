# Кольцо — светлый студийный свет

Оставлен один режим освещения: «Светлый студийный». В просмотрщике нет переключателей света и загрузки внешних HDR-карт.

## Посмотреть

Открой `index.html` двойным кликом. Модель, просмотрщик и декодер встроены в HTML; интернет и сервер не нужны.

Кольцо автоматически вращается на 360° за 16 секунд. Мышь или палец поворачивают его вручную, колёсико или два пальца приближают. Доступны пауза, возврат исходного ракурса и вращение стрелками клавиатуры. После ручного вращения автовращение возобновляется через 2,5 секунды. Системная настройка уменьшения движения учитывается.

## Разместить на сайте

Загрузи `embed.html`, `viewer.js`, `ring-web-v1.glb` и папку `draco/`, сохранив структуру. Эта версия работает через HTTP/HTTPS и не использует CDN.

```html
<iframe src="https://vladaremizova.github.io/game2/ring/embed.html"
        title="Кольцо — просмотр 3D"
        style="display:block;width:100%;height:760px;border:0"
        loading="lazy"></iframe>
```

Для локальной проверки веб-версии запусти `python3 -m http.server 8000` в папке пакета и открой `http://localhost:8000/embed.html`.

## Модель и свет

Геометрия и текстуры сохранены из предоставленного пакета без изменений. GLB весит 2,97 МБ и содержит 153 300 треугольников. SHA-256 модели: `e94bfc600e9ff2021d0a2d08654ddc3e527f952555a2a82f59d9815f3ba1e02a`. Параметры подготовки — в `preparation-report.json`.

Металл и камни используют отдельные нейтральные студии с большими белыми отражателями и узкими тёмными картами. Сохранены параметры предоставленного светлого режима: экспозиция 1,15, размытие металлического окружения 0,004, множитель карты шероховатости 0,70 и кубическая карта камней 512×512. Гравировка и алгоритм внутренних отражений камней сохранены.

Освещение создаётся программно. Настройки — в `bright-studio-settings.json` и `developer-source/studio/createBrightEnvironment.ts`; изображение предоставленного светлого режима — `preview-bright-v3.jpg`. Для сохранения этого вида нужны модель и просмотрщик вместе.

## Пересобрать

Готовый просмотрщик не требует установки зависимостей. Для изменения исходников нужны Node.js и npm:

```sh
cd developer-source
npm install
npm run build
```

Сборка обновляет `viewer.js`, автономный `index.html` и контрольные суммы `sha256.json`. В исходниках оставлен только светлый студийный режим.
